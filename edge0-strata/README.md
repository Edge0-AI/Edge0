# edge0-strata

`edge0-strata` is the engine that `edge0-infer` starts for **Edge0 145B** and **Edge0 120B**. Start with
[EDGE0.md](EDGE0.md): it records where this directory comes from, what was changed and removed, how to
build it, and the launch contract with `edge0-infer`.

It is a fork of [Strata](https://github.com/Niko1221/Strata) by Niko1221 and the Strata contributors,
released under the MIT license ([LICENSE](LICENSE)). Strata's own README, installers, desktop app and
releases are in the upstream repository; the documents under [docs/](docs/README.md) are upstream's and
describe the upstream product, so parts of them refer to files that are not in this directory.

- Running the models: [Edge0 145B](../edge0-infer/docs/edge0-145b.md),
  [Edge0 120B](../edge0-infer/docs/edge0-120b.md).
- Reporting a security issue: [SECURITY.md](SECURITY.md).
- Contributing: [the repository guide](../CONTRIBUTING.md).
