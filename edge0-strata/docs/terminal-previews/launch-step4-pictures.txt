 Should the model read pictures?

   Yes, read pictures  (this engine has no picture reader)






















 ────────────────────────────────────────────────────────────────────────────────────────────────────────────
 Pictures add a 0.9 GB download. On a card under 24 GB the picture reader runs on the CPU (a few seconds per
 picture, nothing taken from the graphics card). On a bigger card it runs on the GPU and keeps about 1.4 GB
 free, costing a few % of text speed. Say No if you only chat in text.
 Heads up: the engine installed here does not carry the picture reader, so the model would answer text only.
