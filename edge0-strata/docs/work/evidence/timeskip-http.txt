# Time-skip through the App Host HTTP API
# repo: bac3f829e92ace1ddd080e502d1f1191d3374c41
# The job is Strata Control's (strata_control/time_skip.py); the Host only starts, follows
# and applies it, and never computes a status of its own.

GET /api/timeskip                     -> run list
GET /api/timeskip/status?id=<run>     -> one durable record
POST /api/timeskip/start              -> start a job; returns immediately with the run
POST /api/timeskip/apply              -> apply or preview; 409 on a concurrent user edit

# Observed:
#   start  -> phase completed, attempt 1 rejected ('deterministic check(s) failed: has-three')
#             checks recorded per checkpoint: has-three=failed, nonempty=passed
#   status -> needsUserReview true, decision inconclusive
#   apply --dry-run -> applied false, would_write []
#   apply after a user edit -> HTTP 409, conflict true, workspace preserved verbatim
