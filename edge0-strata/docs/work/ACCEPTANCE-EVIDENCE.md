## Reading this table

* `passed` means the check ran on this Mac and its evidence is retained. It does not mean the feature works on a machine this is not.
* `failed` is an implementation gap. It is never recorded as `pending-hardware`: deferring a defect to another machine is how defects become permanent.
* `unsupported` names a combination that is not implemented, with the reason.
* Nothing here is a support claim. The macOS candidate is an **unsigned internal development candidate** and is **real-model validation pending**.
