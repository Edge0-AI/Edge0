# R9700 单卡性能摘要

测量日期：2026-10-08。单张 Radeon AI PRO R9700 32 GB，双 EPYC 9334，约 503 GiB 系统 RAM，
Linux / ROCm 7.2.3。主测原版 ISTA GSQ-RCO Qwen3.8-Flash-Next IQ3_S，IQ2_XS 作独立对照。
测试使用冻结的实验版 Strata 0.1.40.3，未测量本 PR 所在的新 upstream 引擎。

本 PR 提交报告和必要复现材料；归档补丁不会应用到当前引擎，也不改变运行默认值。
完整方法、配置和限制见 [英文报告](README.md)。

## 单卡速度

自动专家缓存、自动 prefill、MTP、int8 KV，Tensile 后端；并发 1，每次输出 256 tokens。
每档完整预热后测量三次，正式请求均无提示复用。括号为三次测量的完整范围。

| 输入 tokens | 预填充 tokens/s 中位数（范围） | 生成 tokens/s 中位数（范围） | 原生首 token 延迟中位数 |
| ---: | ---: | ---: | ---: |
| 1,024 | 632.9（514.8–634.0） | 101.9（101.2–102.8） | 1.64 秒 |
| 4,096 | 768.1（716.3–768.8） | 96.4（94.4–100.6） | 5.35 秒 |
| 32,768 | 750.5（750.4–775.4） | 95.6（90.4–98.2） | 43.69 秒 |
| 131,072 | 718.4（713.9–719.0） | 87.6（85.3–91.4） | 182.48 秒 |

计时排除模型加载和预热；首 token 延迟不包含 HTTP/SSE、排队或客户端网络。
单卡仍使用 CPU、系统 RAM 和 PCIe，这些数字不能代表普通桌面 CPU 或最低内存要求。

## 短增量对照

另一套受控配置比较 #1107 的短输入专家分组 gather。保留 32K 历史后新增 512 / 900 tokens，
IQ3_S 五对独立引擎的首 token 延迟配对中位数分别降低 **16.18% / 14.07%**，五对全部更快。
IQ2_XS 两对分别降低 16.21% / 14.96%，样本数较少。

256-token 增量有两对变慢超过 23%；完整输入对照中，IQ3_S 在 4K/32K 的生成耗时增加约
3.5–4.7%，IQ2_XS 有一次 128K 首 token 延迟增加 9.67%。原设置下的严格状态/工作量失败
仍保留，因此这不是全场景默认加速方案。绝对速度与受控收益使用不同配置，不能混算。
